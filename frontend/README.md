Frontend (Next.js) scaffold

- Framework: Next.js
- Styling: Tailwind CSS
- Auth: Supabase (client-side)

This is a minimal scaffold. Install dependencies and run:

```bash
cd frontend
npm install
npm run dev
```

The frontend will handle Supabase sign-in and obtain a JWT. The JWT should be supplied to the CLI or used by the browser to call backend APIs.
